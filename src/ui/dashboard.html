Xem bảng điểm trực tiếp

Bạn có thể xem bảng điểm và sao chép link OBS tại đây.

Cách mở bảng điều khiển

Sao chép giá trị SCOREBOARD_CONTROL_KEY trong mục Environment của dịch vụ Render. Dán giá trị đó ngay sau dấu # trong địa chỉ dưới đây rồi mở bằng Chrome hoặc Edge.

Dữ liệu ngày thi đấu

Trong File Explorer, dùng Copy as path rồi dán vào đây. Dùng Chrome hoặc Edge và giữ tab mở để theo dõi file.
Chọn PlayerNameOverwrite.json.

Sẵn sàng.

KV cho HUD và Scoreboard Realtime

Chọn thư mục KV hoặc một ảnh. Sau khi áp dụng, HUD trong game và bảng điểm trực tiếp sẽ dùng cùng nền KV.

Chọn KV để xem thử. File gốc sẽ được sao lưu trước khi thay.
